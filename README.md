# AI Prompting Fundamentals Activity

Workshop materials for the **Prompt Makeover Activity** , part of the AI for Environmental Data Science module in the Master of Environmental Data Science (MEDS) program.

Students practice iterative prompt engineering by asking an AI to clean a messy column from the [2020 NYC Central Park Squirrel Census](https://www.thesquirrelcensus.com/datap), then verify results with a built-in checking function.

## Contents

| File | Description |
|---|---|
| `activity-starter.qmd` | the main activity worksheet |
| `squirrel-data.csv` | 2020 NYC Central Park Squirrel Census data |

## Activity Structure

The activity runs four rounds, each starting a fresh AI chat:

| Round | Focus |
|---|---|
| 1 | Weak prompt  |
| 2 | Add context & constraints |
| 3 | State assumptions first |
| 4 | Verify all rounds with `check_cleaning()` |
